# Source attribution

This repository consolidates work from **AiCA-Team/AiCA**, developed collaboratively by its A/B/C/D/E contributors. It is not a claim of sole authorship by the owner of this integration repository.

The source snapshot identifiers and module boundaries are recorded in `docs/INTEGRATION_SOURCES.md`, including upstream MCP, preview/renderers, platform, frontend and execution Runtime work. The original team repository remains unchanged. Its Git history was deliberately not imported because it contains private runtime and capture state.

Third-party packages retain their own licenses and notices. Package lockfiles and dependency declarations are included; installed packages, model weights and vendor credentials are not. The Grounding DINO/SAM2 and Hyper3D integrations require users to obtain the appropriate models, services and permissions separately.

The upstream team repository did not declare a recognized root license at consolidation time. This integration does not invent an MIT/Apache license or grant rights beyond those held by the respective authors. Public visibility alone does not establish a redistribution license.
