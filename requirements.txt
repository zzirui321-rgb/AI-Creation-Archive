# AiCA 五人共享开发依赖；每人使用独立的 aica Conda 环境。
# 依据：AiCA_v1.0_Final_Project_Plan.pdf 和 Monorepo角色调整方案.pdf。

# 建议开发栈：CPython 3.12.15、FastAPI、MCP SDK v2、本地 SQLite、外部模型 API。
# Python 框架与数据库是本次环境选型建议，项目文档没有指定这些实现。

# .aica v0.1 是本项目自定义协议，由 A 在 packages/schema/ 维护唯一真源。
# Pydantic/jsonschema 仅提供建模和校验工具，MCP SDK 提供 MCP 通信；均不提供 .aica 实现。

# 已确认：.aica 采用 JSON 加产物链接，支持用户上传自定义工作流，目标为公开用户。
# 采集兼容 Codex、Claude Code 等主流客户端；生图仅用于 Demo，供应商待定。

# 先创建基础环境，所有 Conda 包都应在 pip 安装之前装好：
# conda create -n aica --override-channels -c https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge python=3.12.15 pip nodejs=24.21.0 git 'libsqlite>=3.51.3'

# conda activate aica
# pip install --requirement requirements.txt

# 安装后检查：pip check
# pnpm 安装到当前 Conda 环境，跨平台命令见 docs/SETUP.md。

# React、React DOM、@xyflow/react、TypeScript、Vite 由 Node/pnpm 管理。
# 开始前端开发时，在 package.json 与共享 pnpm lockfile 中固定这些依赖。

# 如需本地视频合成，把 ffmpeg 加入上面的 Conda 创建命令。
# 生图/视频模型通过外部 API 或 MCP 调用，供应商凭证另行配置。

# A / 协议、记录与提取：MCP、Pydantic、Pillow，以及 Conda 提供的 Git。
# D / 运行时、Golden Path、API：FastAPI、Uvicorn、NetworkX、Jinja2、SQLAlchemy、aiosqlite、Alembic。

# B / 预览与产物渲染：HTTPX、Pillow；共享前端展示组件由 Node 包管理。
# C / 核心画布：Node、pnpm、React Flow；此 Python 环境用于后端联调。

# E / 素材、Showcase、集成：使用共享环境准备数据与验证回放。
# 全组质量工具：pytest、pytest-asyncio、pytest-cov、respx、Ruff。

# JSON、ZIP、哈希、日志使用 Python 标准库；本方案无需本地 CUDA/PyTorch。
# 本文件用于 pip install -r，不能传给 conda create --file。

# 下方完整固定直接和传递依赖，平台差异使用环境标记。
