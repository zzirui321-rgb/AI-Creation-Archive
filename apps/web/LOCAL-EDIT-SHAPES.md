# 局部编辑选区

节点详情 → 局部修改此图 → 选择形状并拖动 → 输入修改要求 → 生成预览 → 确认版本。

支持矩形、圆形、椭圆和自动闭合的手绘多边形。矩形与椭圆支持 -180° 到 180° 旋转；使用原图像素计算旋转，避免宽高不同导致变形。靠近图片边缘时选区等比例收缩至原图内。撤销记录包含形状、角度、坐标和轮廓。

前端 `selection-geometry.ts` 负责几何，`LocalEditPanel.tsx` 负责交互。提交的 `local_edit` 包含原图地址、指令、归一化包围框、`shape`、`rotation`、归一化 `points` 和 `feather_px`。原有仅含 `rect` 的记录保持兼容。

独立解析服务 `local_edit.py` 校验轮廓，在包围框周边截取上下文调用现有千问编辑服务；供应商返回后按照真实轮廓合成，只在轮廓内部进行边缘过渡。轮廓外的解码像素逐点保留。该合成约束不等同于模型原生支持任意形状遮罩，选区内生成质量仍由模型决定。

预览、历史恢复、确认版本和导出保留选区描述。前端检查 `local-image-edit-shapes` 能力，旧后端不会静默降级成整图编辑。并排对比点击任一图片，弹窗同时展示原图和修改图；其他视图仍单图放大。
