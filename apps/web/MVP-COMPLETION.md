# 本地 MVP 使用与验收

本次范围由用户确认：本地完整 MVP，补齐导入、编辑、真实预览、历史、Fork、发布与分享闭环。保留原平台设计、分类、发现、收藏、节点弹窗、Remix、增量复用和设置入口。不发布代码到 GitHub。

## 先运行，再配置

打开 <http://127.0.0.1:5173/>。前端使用 5173，独立解析与生成服务使用 8766。需要重新启动时，在本目录运行 `Start-Platform.ps1`；也可以分别启动 `<legacy-local-path>` 和 `npm run dev`。

在「我的设置 → 模型与 API」配置：

1. 生图服务商选择「千问 / 阿里云百炼」。默认模型为 `qwen-image-2.0`；原有已保存设置继续保留，可自行改为账号可用模型。
2. API Base 填写账号对应地域的 API 根地址，例如 `https://dashscope.aliyuncs.com/api/v1`。支持百炼官方业务空间域名。API Key 与地域需要匹配。
3. API Key 在网页中填写并保存后，独立保存在当前浏览器，刷新和重新打开后继续使用；清空并保存可删除。密钥不进入作品、分享快照或服务日志。
4. 团队预览网关留空即可使用本地适配器。已配置的团队网关保持原协议，优先使用。
5. 生视频可选择千问并填写账号可用的 `wan...-t2v` 模型、API Base 与视频 Key。自定义视频服务仍通过团队网关接入。

未填写 Key 且没有网关时，原有模拟预览继续保留，并明确标注。模拟结果不当作真实模型产物。

千问接口按官方[文生图文档](https://help.aliyun.com/zh/model-studio/qwen-image-api)与[文生视频文档](https://www.alibabacloud.com/help/en/model-studio/text-to-video-api-reference)适配。API 模型与权限以账号为准；本次没有使用用户真实凭证进行收费模型验收。

## 修改结果预览

- 上传 JSON 后，解析结果进入原有 Creation Graph。点击节点，在原有弹窗中编辑提示词或使用 A/B/C，再点击「用当前提示词生成预览」。
- 配有 Key 或团队网关时，使用修改后的提示词和选用模型请求生成。显示请求、供应商生成、保存结果等状态；失败时提示错误，可重新生成。
- 保留「修改结果 / 节点原结果 / 并排对比」。选中节点时只展示该节点的历史结果；无关联结果时显示占位，不用其他节点图片代替。
- 「参考原图生成」将可用原图作为输入，适用于支持编辑的千问模型，例如 `qwen-image-2.0`。原版 `qwen-image` 只能文生图；不支持的组合会报错，不忽略原图继续生成。
- 千问原生图片和视频结果下载到本机缓存，避免供应商临时链接失效。结果可放大和下载，视频支持 Range 播放。团队网关返回的地址仍由该网关负责持久化。
- 「确认最终版本」确认现有结果，不重复调用模型。确认的结果用于封面、发布与图片分享卡片。
- 修改提示词不会删除历史。旧结果与当前节点不一致时会提示，不能直接当成当前修改的确认结果。
- 取消会停止本地等待和结果接收；已提交的供应商任务可能仍在运行、计费，不承诺远程任务已被撤销。

## 历史、Fork、发布与分享

- 历史记录保存节点、提示词、模型、产物、时间和确认状态，可恢复相应提示词、模型与结果。已完成记录在刷新后保留。
- Fork 保留来源和原作品结果作为对比基线，新建自己的编辑与预览历史。
- 原有保存草稿和本机社区发布继续使用。确认后的图片或视频替换示意封面。
- 复制本地作品分享链接时，服务保存只读快照。同一台电脑的其他浏览器可通过该链接查看和 Fork，不依赖原浏览器 localStorage。它仍是本机地址，不是公网部署。
- 分享卡片可以使用已确认图片；视频或尚未确认的作品使用明确标注的示意封面。保留原有 PNG 下载。
- 导出记录包含图、预览历史和封面引用；再导入时重新映射节点 ID，并保留历史。产物仍引用本机缓存，JSON 导出不是包含全部二进制文件的跨电脑素材包。

## 结果节点与布局

Creation Graph 以已记录的生成结果为节点，单次请求的多个候选结果保存在同一节点中；保存、复制、失败和没有结果的讨论保留在来源记录。节点中的图片、视频或文本为历史结果，编辑提示词不会覆盖它。确认真实预览后新增版本节点，模拟预览仍明确标注。

任务框默认横向排列，内部主线向右、分支向下；纵向时任务框向下、主线向下、分支向右，接口和连线同步更新。旧导入记录在详情页从本地服务补齐结果关联，并保留现有提示词、模型修改和预览历史。未记录执行 ID 的独立文件显示关联待确认，文件名候选不作为已验证的执行关系。


## 矩形框选局部编辑

打开结果节点，在「此节点的生成结果」中点击「局部修改此图」。拖动框选或填写选区百分比，输入修改要求，可调边缘过渡、撤销或清除框选。点击「生成局部修改预览」后，在右侧使用「并排对比」查看精确保存的底图与合成结果；确认后新增版本节点。

局部编辑使用设置中的千问生图模型与生图 API Key，优先经过本地适配器，不使用另行配置的团队预览网关，也不会在缺少密钥时显示模拟编辑成功。只将选区及其周围上下文交给模型，合成保留选区外的解码像素。首版支持矩形选区；蒙版画笔和跨节点自动同步不包含在此版本中。供应商可能仍按整次生成计费。
